# Flood_info
 Flood Analysis in Kerala (1901–2018)
This Jupyter Notebook presents a comprehensive analysis of flood events in Kerala, India, from 1901 to 2018. The project visualizes historical flood data using Matplotlib to identify trends, patterns, and the frequency of major flood occurrences over time. It aims to provide insights into the long-term impact of floods in the region and support further research or disaster preparedness planning.
