# Flood_info
 Flood Analysis in Kerala (1901–2018)
This project presents a historical data analysis of flood events in Kerala, India, spanning from 1901 to 2018. Using Python and Matplotlib, it visualizes flood trends over time to reveal patterns, frequency, and long-term changes in flood behavior.

📌 Project Overview
📅 Time Range: 1901–2018

🧰 Tools Used: Python, Jupyter Notebook, Matplotlib,seaborn,pandas

📊 Focus: Visualization and trend analysis of historical flood data in Kerala

The aim is to better understand the evolution of flood events, potentially aiding in future disaster preparedness and climate resilience planning.

📈 Key Features
Line and bar plots to illustrate flood frequency across decades
Visual representation of major flood years
Insights into how flood patterns have shifted over the 20th and 21st centuries
Clean and modular code using standard Python libraries

🛠️ Technologies Used
Python 3.x
Jupyter Notebook
Matplotlib for data visualization
Pandas
